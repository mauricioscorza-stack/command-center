Tema

Google Tasks

Como conectar (5 min)
  1. Logado no Gmail do trabalho, abra script.google.com → Novo projeto e cole o arquivo Code.gs. Salve.
  2. Em Serviços (+), adicione Google Tasks API.
  3. Escolha a função setup e clique em ▶ Executar. Autorize. O token aparece no Registro de execução e em Configurações do projeto → Propriedades do script → CC_TOKEN.
  4. Implantar → Nova implantação → App da Web. Executar como: Eu. Quem pode acessar: Qualquer pessoa.
  5. Cole abaixo a URL (termina em /exec) e o token, depois clique em Testar conexão.

Triagem com IA

Usar uma chave neste navegador (sem Apps Script)

O recomendado é guardar a chave no Apps Script, em Propriedades do script → GEMINI_API_KEY. Use este campo só se não for conectar o Google Tasks.
